# David Mason Portfolio

A creative, interactive portfolio website featuring scroll-driven animations, parallax effects, custom illustrations, and playful interactive elements. Each experience section has its own visual identity, creating an engaging alternative to a traditional portfolio.

## Overview

The portfolio presents professional experience, creative work, side projects, and personal achievements through a visually rich scrolling experience. Each company section uses its own colour palette and interactive illustrations, with animated transitions connecting the different stages of the journey.

## Features

- **Scroll-Driven Animations** — Smooth, layered transitions between experience sections.
- **Interactive Visual Design** — Custom illustrations and playful objects that complement each section.
- **Distinct Company Themes** — Individual colour palettes and visual elements for each professional experience.
- **Side Projects Showcase** — A horizontal project gallery with GitHub star counts.
- **Interactive Notifications** — Humorous notifications and a simulated Do Not Disturb experience.
- **Cookie Banner Interaction** — A playful cookie consent banner with interactive behaviour.
- **DavidBot™** — A lightweight, regex-based chatbot with humorous responses.
- **Responsive Design** — Layouts designed for desktop, tablet, and mobile screens.
- **Accessibility and Quality Checks** — Automated checks for layout overflow, broken links, and interface issues.

## Technology Stack

| Technology | Purpose |
|---|---|
| TypeScript | Application logic and type safety |
| Vite | Development server and production build |
| GSAP ScrollTrigger | Scroll-based animations and transitions |
| Lenis | Smooth scrolling |
| HTML5 | Website structure |
| CSS3 | Styling, layouts, and visual effects |
| GitHub Pages | Website hosting and deployment |
| GitHub Actions | Automated deployment workflow |

## Deployment

The project uses GitHub Pages for hosting, with a GitHub Actions workflow configured to deploy changes when code is pushed to the main branch.

For the original portfolio deployment, visit:

**[Live Portfolio](https://yenaing-it.github.io/David-Mason-Portfolio/)**

## Quality Assurance

The project includes automated checks to help validate the website across different screen sizes and interaction states.

- Responsive layout and overflow checks
- UI interaction tests
- Mobile touch and swipe tests
- External link validation
- Screenshot-based visual inspection
